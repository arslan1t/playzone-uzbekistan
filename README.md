# Apex Arena Investor Deck Prototype

Premium React + TypeScript + Vite sample deck for a modern multi-sport complex.

## What this version is

This is not a finished business plan.
It is a polished editable prototype with:

- stronger slide structure
- better investor logic
- placeholder blocks for real numbers
- premium dark visual style
- reusable layout system for future edits
