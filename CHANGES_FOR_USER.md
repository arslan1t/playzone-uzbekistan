# Что изменено

## Основное
- Полностью переработан `src/app/InvestorDeck.tsx`.
- Проект теперь выглядит как investor-facing interactive deck, а не просто набор перегруженных экранов.
- Использованы уже готовые тексты и материалы из существующего проекта.

## Что улучшено в дизайне
- Добавлена стабильная левая навигация по всем 16 слайдам.
- Сделан сильный главный экран: крупный заголовок, подзаголовок, spotlight-метрики.
- Справа вынесен отдельный блок логики слайда и supporting materials.
- Фон теперь меняется по слайдам и использует реальные проектные рендеры/планы.
- Визуальный стиль стал чище: меньше визуального шума, лучше иерархия, более премиальный вид.

## Что улучшено в логике
- Навигация по hash (`#slide-01`, `#slide-02`, ...).
- Поддержка клавиш: `←`, `→`, `PageUp`, `PageDown`, `Home`, `End`.
- Каждый слайд теперь имеет отдельную понятную структуру:
  - проблема
  - спрос
  - operating model
  - layout / zoning
  - monetization
  - unit economics
  - schedule
  - growth
  - returns
  - competition
  - investment ask
  - scalability

## Важное замечание
В исходном архиве `node_modules` пришёл в сломанном виде (macOS zip + битые исполняемые файлы Vite), поэтому для нормальной сборки лучше:
1. удалить `node_modules`
2. выполнить `npm install`
3. затем `npm run dev` или `npm run build`
